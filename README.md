## Project Overview

This project was developed as part of a programming challenge focused on the efficient use of vectors and matrices in C++. The main objective was to structure data using multidimensional arrays and perform operations on them in a clear and organized way.

-----
### What was done

- Structured data efficiently using vectors and matrices
- Implemented operations that process and manipulate matrix-based information
- Displayed results in a clear and organized format
- Wrote clean, well-documented code with meaningful comments
- Focused on code readability and maintainability for future improvements

------

### Challenges faced

During development, the main challenges were:

- Organizing data correctly with matrices to keep the solution efficient
- Ensuring operations ran without noticeable delays
- Keeping the code structured and easy to understand while handling multidimensional data
- Balancing clarity of output with good performance
